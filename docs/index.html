Method

From scene physics to radar response.

The source does not reduce the condition to a text label. It rasterizes material and geometry, derives propagation and response priors, and injects all five physical groups throughout the velocity network.

PCFlow source pipeline: physical scene encoding, latent rectified-flow training and ODE decoding.

01 / CONDITION

Maxwell-informed fields

Coordinates, εr, σ, impedance, attenuation, phase, interfaces, pipe geometry, travel time and response priors form one interpretable 26-channel tensor.

02 / NETWORK

Physics-SPADE U-Net

Geometry, material, reflection, propagation and detail groups modulate residual blocks across a four-level U-Net, with attention at its lower resolutions.

03 / GENERATION

Rectified-flow ODE

The U-Net learns a latent velocity from noise to data. Euler or Heun integration then transports a random SDXL latent into a synthesized B-scan.

Training loop

A reproducible five-stage path.

The main preset uses AdamW, automatic mixed precision, gradient clipping and EMA. Conditions are dropped for 10% of samples during training, while deeper latent rows receive greater loss weight.

Load pairRead a grayscale PNG and its matching gprMax `.in` scene.
Build physicsRasterize εr, σ and geometry, then compute the 26-channel condition.
Encode latentConvert to pseudo-RGB and use the frozen SDXL VAE to obtain z₁.
Match velocitySample z₀ and t, construct zₜ, then predict v = z₁ − z₀.
Track progressUpdate EMA; log, validate, sample and checkpoint on configured intervals.

Quick start

Clone, install, train.

Use Python 3.10 and install the CUDA-enabled PyTorch build suited to your system. The first run downloads the frozen `stabilityai/sdxl-vae` unless a local path is configured.

setup
git clone https://github.com/GeometryFu/PCFlow.git
cd PCFlow/PCFlow

conda create -n pcflow python=3.10 -y
conda activate pcflow

# Install a suitable CUDA-enabled PyTorch build first
pip install -r requirements.txt
python train.py
The repository does not currently publish a PCFlow checkpoint or official paper identifier. This page intentionally omits placeholder download, benchmark and citation claims. See the README for current sampling behavior and implementation notes.
