PCFlow

Physics-Conditioned Flow Matching for GPR Pipeline Synthesis

A novel framework for fast GPR B-scan synthesis, achieving high visual fidelity and strong physical consistency via Maxwell-informed condition fields.

Quick Start

Ready to Run

Clone the repo, install dependencies, and generate your first physically consistent GPR B-scan in minutes.

1

Clone & Install Dependencies

# Clone the repository
$ git clone https://github.com/GeometryFu/PCFlow.git
$ cd PCFlow

# Create conda environment
$ conda create -n pcflow python=3.10 -y
$ conda activate pcflow

# Install dependencies
$ pip install -r requirements.txt
$ pip install -e .
2

Download Pre-trained Weights

# Download weights from HuggingFace (Coming Soon)
$ mkdir -p checkpoints
$ wget https://huggingface.co/xxx/PCFlow/resolve/main/pcflow_base.pth -P checkpoints/

Weights are coming soon. Please check the HuggingFace link later.

3

Run Inference

# Generate B-scan from physical condition parameters
$ python inference.py --config configs/pcflow_base.yaml --checkpoint checkpoints/pcflow_base.pth --condition examples/sample_params.yaml --output results/

# Train your model
$ torchrun --nproc_per_node=4 train.py --config configs/pcflow_base.yaml

Method

Method Overview

PCFlow constructs a Maxwell-informed dense physical condition field from parameterized physical models. This condition field guides conditional flow matching in the VAE latent space, reducing transport variance and generating physically feasible GPR B-scans.

pipeline.png — Method Architecture

Figure 2: Overview of PCFlow. A Maxwell-informed condition encoder transforms simulation parameters into dense physical fields, guiding the flow matching process in the VAE latent space.

Maxwell-Informed Conditioning

Encodes material properties, target geometry, propagation cues, and response-domain priors into an interpretable dense condition field.

Physical Consistency

Ensures the generated hyperbolic responses appear at correct lateral positions, depths, and aperture shapes determined by the physical scene.

Fast & Controllable

Formulates synthesis as conditional flow matching with Classifier-Free Guidance, achieving fast and deterministic physically aligned generation.
